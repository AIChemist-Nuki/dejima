# Dejima

**Mac でローカル翻訳。⌘C を2回押すだけ。**

テキストを選んで ⌘C を続けて2回押すと、ポインタのそばに訳文が表示されます。Dejima はアプリの右クリックの翻訳メニューに依存せず、別のアプリへ切り替える必要もありません。必要なモデルの準備ができれば、オフラインで使えます。

## 3つのステップで始める

### 1. インストールして、アクセスを許可

ダウンロードした DMG を開き、使用中のシステムに合う **macOS 15〜25** または **macOS 26 以降** フォルダを選びます。`Dejima.app` を Applications にドラッグしてから起動してください。

アプリの案内に従ってシステム設定のアクセシビリティのリストを開き、Dejima をドラッグして許可をオンにします。許可されると、案内ウィンドウは自動で閉じます。

<img src="docs/images/accessibility.jpg" alt="Dejima のアクセシビリティ設定ガイド、英語表示" width="420">

### 2. 翻訳先の言語を選ぶ

画面上部のメニューバーにある Dejima のアイコンをクリックします。

- **翻訳先**：通常の訳文の言語。
- **すでにその言語なら**：原文が「翻訳先」と同じ言語だった場合に使う、もう一つの訳文の言語。

どちらも訳文の言語を選ぶ設定で、原文の言語は自動判定します。例えば **翻訳先＝簡体中国語、すでにその言語なら＝英語** にすると、**英語 → 中国語、中国語 → 英語** になります。

初期設定は簡体中国語と日本語です。必要に応じて変更してください。

### 3. 選択して、⌘C、⌘C

Web ページや書類でコピーできる文章を選択し、⌘ を押したまま C を素早く2回押します。ポインタのそばに訳文が表示されます。パネルの外をクリックするか Esc を押せば、そのまま読み進められます。

**言語モデルがないと表示された場合**

すでに翻訳できる場合は、この手順を省略できます。システムのダウンロード案内が表示された場合は、その案内に従ってください。

1. Dejima のメニューで **翻訳言語の設定…** を選び、システム設定の **Language & Region** を開きます。設定画面が開くだけで、自動的にダウンロードされるわけではありません。
2. **Translation Languages…** をクリックします。
3. エラーに表示された原文と訳文の言語で **Download** をクリックし、**両方**をダウンロードします。例えば英語と簡体中国語です。
4. 完了を待ち、元の文章に戻って ⌘C を2回押します。

<img src="docs/images/languages.jpg" alt="macOS のシステム設定にある翻訳言語のダウンロード一覧、英語表示" width="420">

*システムの翻訳言語ダウンロード一覧。英語表示です。*

Dejima の[翻訳は端末内で処理される](https://developer.apple.com/documentation/translation/translationsession)ため、画像の **On-Device Mode** をオンにする必要はありません。このシステム設定は、Dejima の Apple Intelligence による追加の推敲とは別のものです。

## 気持ちよく使うために

- **言語の判定。** 短いテキストでは原文の言語を誤判定することがあります。
- **コピーとピン留め。** コピーボタンで訳文をコピーできます。ピン留めすると、外をクリックしてもパネルが開いたままになります。Esc では閉じられます。
- **訳文をさらに推敲。** **Apple Intelligence で推敲** は翻訳後に追加で文章を整える機能で、初期設定ではオフです。macOS 26 以降でモデルが利用できる場合に表示されます。推敲に失敗した場合は、最初の訳文を表示します。
- **表示言語。** システム設定に従い、日本語、英語、簡体中国語、韓国語に対応しています。それ以外は英語で表示します。

[翻訳アプリの比較](docs/Comparison.md)（英語）もご覧ください。

## プライバシー

翻訳と推敲は端末内で処理します。言語モデルのダウンロードにはインターネット接続が必要です。

更新確認では GitHub に接続しますが、翻訳したテキスト、利用状況、アプリが生成した識別子は送りません。自動確認は初期設定ではオフです。オンにすると、前回の確認成功から24時間以上経過した起動時に確認します。失敗した場合は、次回の起動時に再試行することがあります。

## 名前について

Dejima の名前は、長崎の人工島[「出島」](https://nagasakidejima.jp/history/)に由来します。江戸時代、日本と西欧の貿易や知識・文化の交流を支える窓口となりました。
