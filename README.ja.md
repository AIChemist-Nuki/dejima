# Dejima

macOS のメニューバーで使う翻訳アプリです。テキストを選択して ⌘C を2回押すと、ポインタの近くに訳文を表示します。

[简体中文](README.md) · [English](README.en.md) · [한국어](README.ko.md)

## インストール

macOS 15 以降が必要です。[Releases](https://github.com/AIChemist-Nuki/dejima/releases/latest) から DMG をダウンロードし、使用中の macOS に合うフォルダを開いて、`Dejima.app` を Applications にドラッグしてください。

1. Dejima を起動し、案内に従ってシステム設定のアクセシビリティのリストに追加し、許可をオンにします。
2. メニューの **言語モデルを確認…** から、使う言語をダウンロードします。
3. テキストを選択して ⌘C を続けて2回押します。

Dejima はメニューバーに常駐し、Dock アイコンやメインウィンドウはありません。反応しない場合は、実行中の Dejima にアクセシビリティ権限があるか、監視が一時停止になっていないかを確認してください。

## 使い方

- メニューの **翻訳先** で主言語、**すでにその言語なら** で副言語を選びます。主言語のテキストは副言語へ、それ以外は主言語へ翻訳します。初期設定は簡体中国語と日本語です。短いテキストでは言語を誤判定することがあります。
- コピーボタンで訳文をコピーできます。パネルの外をクリックするか Esc を押すと閉じます。ピン留めすると外をクリックしても開いたままになります。Esc では閉じられます。
- **Apple Intelligence で推敲** は任意の機能で、初期設定ではオフです。macOS 26 以降と、利用可能な Apple Intelligence モデルが必要です。推敲に失敗した場合は、最初の訳文を表示します。
- 表示言語はシステム設定に従い、英語、簡体中国語、日本語、韓国語に対応しています。それ以外は英語で表示します。

## プライバシー

翻訳と推敲は端末内で処理します。言語モデルのダウンロードにはインターネット接続が必要です。

更新確認では GitHub に接続しますが、翻訳したテキスト、利用状況、アプリが生成した識別子は送りません。自動確認は初期設定ではオフです。オンにすると、前回の確認成功から24時間以上経過した起動時に確認します。失敗した場合は、次回の起動時に再試行することがあります。

## ビルド

macOS 26 以降の SDK を含む Xcode 26 以降と、XcodeGen が必要です。

```bash
brew install xcodegen
xcodegen generate
open Dejima.xcodeproj
```

`Dejima` または `Dejima26` スキームを選び、署名を設定してください。ビルドの違いと配布用パッケージの作成方法は [Development](docs/Development.md) を参照してください。
