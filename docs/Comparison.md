# Translation tools on Mac

Checked on **2026-10-13**. This is a comparison of workflows and documented capabilities, not a performance benchmark. Competitor apps were not installed or tested for this comparison.

Dejima provides a focused way to reach Apple's local translation from applications that let you copy text, including places where the system Translate menu is unavailable. Its scope is selected text; Bob and Easydict also cover workflows such as OCR and comparing several providers.

## What this comparison establishes

- **A desktop app is not necessarily an offline translator.** DeepL's desktop app needs internet access. Its double-copy shortcut and floating window are already documented features, so neither is unique to Dejima.
- **System translation has more than one execution path.** The macOS right-click interface can use servers or On-Device Mode. Dejima calls [`TranslationSession`](https://developer.apple.com/documentation/translation/translationsession), which processes translations on device; Dejima does not require the system's On-Device Mode checkbox to be enabled. Its newer [`highFidelity` strategy](https://developer.apple.com/documentation/translation/translationsession/strategy/highfidelity?language=objc) uses Apple Intelligence models when available and falls back to traditional models otherwise. Apple documents [`lowLatency`](https://developer.apple.com/la/documentation/translation/translationsession/strategy/lowlatency) as the default on devices without Apple Intelligence and for apps built with SDKs earlier than macOS 26.4.
- **Offline capability has prerequisites.** Required on-device models must be available. Traditional translation models require language downloads; the `highFidelity` models are already downloaded when Apple Intelligence is enabled, so that path does not require additional language downloads. Initial model downloads require a connection. Supported languages and model availability depend on the system and service.
- **Apple Intelligence refinement is a separate step in Dejima.** The draft may already use Apple Intelligence through the system translation strategy, independently of Dejima's refinement switch. A preferred strategy is not a per-request inference trace, and a successful draft does not prove refinement ran. Verify the refinement setting, model availability, and that step's outcome; output wording alone is not reliable evidence.
- **No speed, translation-quality, or battery ranking is claimed.** The architecture and documented features do not establish which app is faster, more accurate, or more efficient. Measuring only an app's own process would also omit work performed by macOS translation and model services.
- **Documentation is not an app compatibility test.** The absence of a Translate item can depend on the app, view, and version. This comparison does not assert universal compatibility with Slack, Claude, or ChatGPT. Easydict references above describe its current `dev` documentation, not a release tested here.
