# Dejima

macOS 메뉴 막대 번역 앱입니다. 텍스트를 선택하고 ⌘C를 두 번 누르면 포인터 옆에 번역문을 표시합니다.

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

## 설치

macOS 15 이상이 필요합니다. [Releases](https://github.com/AIChemist-Nuki/dejima/releases/latest)에서 DMG를 내려받고, 사용 중인 macOS 버전에 맞는 폴더를 열어 `Dejima.app`을 응용 프로그램 폴더로 드래그하세요.

1. Dejima를 실행합니다. 안내에 따라 시스템 설정의 손쉬운 사용 목록에 앱을 추가하고 권한을 켭니다.
2. 메뉴에서 **언어 모델 확인…**을 선택하고 필요한 언어를 내려받습니다.
3. 텍스트를 선택하고 ⌘C를 빠르게 두 번 누릅니다.

Dejima는 메뉴 막대에서 실행되며 Dock 아이콘이나 메인 창은 없습니다. 반응이 없으면 실행 중인 앱에 손쉬운 사용 권한이 있는지, 감지가 일시 정지되어 있지 않은지 확인하세요.

## 사용

- 메뉴의 **번역할 언어**와 **이미 그 언어라면**에서 주 언어와 보조 언어를 설정합니다. 주 언어로 된 텍스트는 보조 언어로, 그 밖의 텍스트는 주 언어로 번역합니다. 기본값은 중국어 간체와 일본어입니다. 짧은 텍스트는 언어를 잘못 감지할 수 있습니다.
- 복사 버튼으로 번역문을 복사합니다. 패널 바깥을 클릭하거나 Esc를 누르면 닫힙니다. 고정하면 다른 곳을 클릭해도 열린 상태를 유지하며, Esc로는 닫을 수 있습니다.
- **Apple Intelligence로 다듬기**는 선택 기능이며 기본값은 꺼짐입니다. macOS 26 이상과 사용 가능한 Apple Intelligence 모델이 필요합니다. 다듬기에 실패하면 초벌 번역을 유지합니다.
- 인터페이스는 시스템 언어를 따릅니다. 영어, 중국어 간체, 일본어, 한국어를 지원하며, 그 밖의 언어에서는 영어로 표시됩니다.

## 개인정보

번역과 다듬기는 기기에서 처리합니다. 언어 모델을 내려받을 때는 인터넷 연결이 필요합니다.

업데이트 확인 시 GitHub에 연결하며, 번역한 텍스트·사용 보고서·앱이 생성한 식별자는 보내지 않습니다. 자동 확인은 기본값이 꺼짐입니다. 켜면 마지막으로 확인에 성공한 뒤 24시간이 지난 경우 앱 실행 시 확인합니다. 실패하면 다음 실행 때 다시 시도할 수 있습니다.

## 빌드

macOS 26 SDK 이상을 포함한 Xcode 26 이상과 XcodeGen이 필요합니다.

```bash
brew install xcodegen
xcodegen generate
open Dejima.xcodeproj
```

`Dejima` 또는 `Dejima26` 스킴을 선택하고 서명을 설정하세요. 빌드 간 차이와 릴리스 패키징은 [개발 문서](docs/Development.md)를 참고하세요.
