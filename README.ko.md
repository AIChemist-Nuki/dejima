## 세 단계로 시작하기

### 1. 설치하고 권한 허용하기

내려받은 DMG를 열고 시스템에 맞는 **macOS 15~25** 또는 **macOS 26 이상** 폴더를 선택합니다. `Dejima.app`을 응용 프로그램 폴더로 드래그한 뒤 실행하세요.

앱의 안내에 따라 시스템 설정의 손쉬운 사용 목록을 엽니다. Dejima를 목록에 드래그하고 권한을 켜세요. 권한이 허용되면 안내 창이 자동으로 닫힙니다.

<img src="docs/images/accessibility.jpg" alt="Dejima 손쉬운 사용 권한 안내, 영어 인터페이스" width="420">

### 2. 사용할 언어 준비하기

Dejima는 메뉴 막대에서 실행되며 Dock 아이콘이나 메인 창은 없습니다. 메뉴 막대의 아이콘을 클릭하고 **번역할 언어**와 **이미 그 언어라면**에서 자주 쓰는 두 언어를 선택합니다.

**언어 모델 확인…**을 누르면 시스템 설정의 **Language & Region**이 열립니다. **Translation Languages…**를 클릭하고 원문과 번역문에 필요한 언어를 모두 내려받으세요. 준비가 끝나면 Mac에서 오프라인으로 번역할 수 있습니다.

<img src="docs/images/languages.jpg" alt="macOS 시스템 설정의 번역 언어 다운로드 목록, 영어 인터페이스" width="420">

*시스템의 번역 언어 다운로드 목록입니다. 영어 인터페이스로 표시됩니다.*

### 3. 선택하고, ⌘C, ⌘C

웹페이지나 문서에서 복사할 수 있는 글을 선택하고, ⌘를 누른 채 C를 빠르게 두 번 누릅니다. 포인터 옆에 번역문이 나타납니다. 패널 바깥을 클릭하거나 Esc를 누르면 계속 읽을 수 있습니다.

## 편하게 사용하기

- **자동 언어 전환.** 주 언어로 된 텍스트는 보조 언어로, 그 밖의 텍스트는 주 언어로 번역합니다. 기본값은 중국어 간체와 일본어입니다. 짧은 텍스트는 언어를 잘못 감지할 수 있습니다.
- **복사와 고정.** 복사 버튼으로 번역문을 복사합니다. 패널을 고정하면 바깥을 클릭해도 열린 상태를 유지하며, Esc로는 닫을 수 있습니다.
- **선택적 다듬기.** **Apple Intelligence로 다듬기**는 기본값이 꺼짐이며, macOS 26 이상에서 모델을 사용할 수 있을 때 표시됩니다. 다듬기에 실패하면 초벌 번역을 유지합니다.
- **인터페이스 언어.** 시스템 언어를 따르며 한국어, 영어, 중국어 간체, 일본어를 지원합니다. 그 밖의 언어에서는 영어로 표시됩니다.

<details>
<summary>⌘C를 두 번 눌러도 반응이 없나요?</summary>

텍스트를 복사할 수 있는지, 실행 중인 Dejima에 손쉬운 사용 권한이 있는지, 메뉴에서 감지가 일시 정지되어 있지 않은지 확인하세요. 언어 모델이 없다는 메시지가 표시되면 **언어 모델 확인…**에서 내려받은 뒤 다시 복사하세요.

</details>

## 개인정보

번역과 다듬기는 기기에서 처리합니다. 언어 모델을 내려받을 때는 인터넷 연결이 필요합니다.

업데이트 확인 시 GitHub에 연결하며, 번역한 텍스트·사용 보고서·앱이 생성한 식별자는 보내지 않습니다. 자동 확인은 기본값이 꺼짐입니다. 켜면 마지막으로 확인에 성공한 뒤 24시간이 지난 경우 앱 실행 시 확인합니다. 실패하면 다음 실행 때 다시 시도할 수 있습니다.
